API documentation

Create payments from your website or app, and let customers pay via bKash Send Money with TrxID verification. No bKash API key needed.

Authentication

Generate an API key in your dashboard and send it in the X-API-Key header with every request.

X-API-Key: ap_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Create a payment

POST /api/v1/create-payment

{
  "amount": 128.55,
  "currency": "BDT",
  "merchantInvoiceNumber": "ORDER-123",
  "customerRef": "customer@example.com",
  "callbackURL": "https://your-site.com/payment-done"
}

Response (201):

{
  "payment_id": "AP9F2C...",
  "payment_url": "https://pay.atikur.cyou/pay/AP9F2C...",
  "amount": 128.55,
  "currency": "BDT",
  "status": "pending"
}

Send your customer to payment_url. They send the money via bKash, enter the TrxID, and the payment is auto-verified.

Check payment status

GET /api/v1/payment/status?payment_id=AP9F2C...

{
  "payment_id": "AP9F2C...",
  "status": "paid",
  "amount": 128.55,
  "currency": "BDT",
  "method": "bkash",
  "trx_id": "9HX7K2M4P1",
  "merchant_invoice_number": "ORDER-123"
}

Statuses: pending, paid, failed, cancelled.

SMS ingest (Android app)

The Android app on the merchant's phone forwards incoming bKash SMS here, so TrxIDs can be verified automatically.

POST /api/sms

Headers:

X-SMS-Secret: <SMS ingest secret>
X-API-Key: <merchant API key>
Content-Type: application/json

Body:

{
  "sender": "01712345678",
  "amount": 128.55,
  "trx_id": "9HX7K2M4P1",
  "sms_text": "You have received Tk 128.55 from 01712345678...",
  "method": "bkash"
}

Response (201): {"status": "stored", "trx_id": "9HX7K2M4P1"}. Sending the same TrxID again returns {"status": "duplicate"} — ingest is idempotent.
